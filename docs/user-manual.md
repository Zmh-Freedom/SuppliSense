# 供应商智能寻源与风险监控工作台｜用户操作手册

**版本：** 1.0
**更新日期：** 2026-09-16
**适用对象：** 采购员、科室经理、系统管理员
**适用场景：** 供应商风险监控、风险复核、替代寻源、候选核验和采购跟进。

> 本系统提供的是可追溯的风险复核线索、寻源候选和处理建议，不替代供应商准入、现场审计、质量审核、报价决策或合同审批。页面显示“数据不足”“当前未覆盖”时，不应理解为“没有风险”。

---

## 1. 使用前先了解两件事

### 1.1 系统能帮助完成什么

- 从采购工作台查看本人负责范围内的风险变化、数据覆盖和待跟进事项；
- 用 **AI 采购助手** 询问单家供应商风险、结论依据、下一步建议和寻源需求；
- 在风险监控页查看供应商快照、已回写的证据、数据缺口和复核任务；
- 按物料或品类查询历史合作供应商、正式供应商和外部待核验候选；
- 在风险监控页完成“调查—确认主体并加入监控”，或在 AI 采购助手出现审批卡时批准/拒绝相应提案；
- 接收按责任范围汇总的飞书风险日报和告警通知（以实际部署、权限及投递记录为准）。

### 1.2 必须遵守的使用边界

1. 外部待核验候选只是寻源线索，**不是**正式供应商，不能据此跳过准入、质量、价格或产能核验。
2. 风险评分和 AI 建议是辅助信息；采购人员需结合原始证据、数据时间、项目情况和线下核实后再决策。
3. 系统仅展示当前账号有权限查看的供应商范围。出现“权限不足”时，请联系管理员维护责任关系，不要尝试绕过限制。
4. AI 采购助手中出现的写操作提案需要在审批卡上人工批准；风险监控页面的“确认主体并加入监控”按页面确认流程执行。请以页面实际展示的操作和提示为准。
5. 请勿在问题中输入合同价格、身份证号、银行账户、账号密码、接口密钥等不必要的敏感信息。

## 2. 登录、角色与页面入口

### 2.1 登录

1. 打开管理员提供的系统地址。
2. 输入用户名和密码，点击“登录”。
3. 登录后，默认进入 **采购工作台**。
4. 使用完成后，从账号菜单退出登录；公共电脑不要保存浏览器密码。

如登录失败，请先核对账号是否启用；连续失败、账号锁定或无权限时联系管理员处理。

### 2.2 角色与权限

| 角色 | 可查看范围 | 主要操作 |
| --- | --- | --- |
| 采购员 | 本人负责的正式供应商、相关监控对象、风险快照和通知 | 风险查询、复核、寻源、提交受控操作 |
| 科室经理 | 所属科室责任范围内的供应商和汇总信息 | 查看团队风险、跟进复核事项、查看通知汇总 |
| 管理员 | 已授权的全量数据和运维配置 | 当前前端可查看账户信息、修改密码；账号、责任关系、数据同步和通知任务由飞书主数据或部署后台维护 |

> 同一页面对不同角色显示的对象可能不同，这是责任范围控制的正常表现。

## 3. 快速开始：三条最常用业务路径

### 路径 A：复核一家供应商的风险

适用场景：需要判断某家供应商近期是否有值得关注的经营、司法、财务、舆情或交易变化。

1. 点击 **AI 采购助手**，点击“+ 新对话”。
2. 输入完整问题，例如：
   `查看一下青岛三祥科技股份有限公司的风险情况`
3. 等待回答完成，先查看顶部的风险结论和当前建议。
4. 向下查看风险维度、证据、数据时间和数据覆盖说明。
5. 在同一会话继续追问：
   - `风险结论主要依据哪些数据？`
   - `这家供应商下一步建议怎么处理？`
6. 如需要线下跟进，打开对应供应商的风险监控详情，查看已有复核任务、证据和处理记录。

**判断要点：**

- 先看结论是否有数据覆盖说明；
- 再看每项信号对应的来源和数据时间；
- 最后看建议动作和优先级；
- 如果页面提示数据不足，请查看缺失的数据域，必要时按组织流程线下核验或在数据更新后重新发起复核；不能直接认为供应商安全。

### 路径 B：发现风险后准备替代资源

适用场景：现有供应商需要重点复核，或项目需要提前准备备选供应来源。

1. 在 **AI 采购助手** 中点击“+ 新对话”。
2. 输入物料或品类需求，例如：
   `找一下安全带的供应商`
3. 查看系统返回的候选分组：
   - 历史合作供应商；
   - 正式供应商；
   - 外部待核验候选。
4. 对候选逐项核对匹配品类、主营产品、所在地、来源和当前核验状态。
5. 需要更多筛选条件时，进入 **寻源建议**，补充规格、交付区域、质量体系、产能或其他限制条件。
6. 将候选作为采购调研线索，按组织流程完成主体资料、资质、质量、价格、产能和准入核验。

**特别提醒：** 外部待核验候选不能直接作为定点或正式供应商；候选资料缺失时应记录待补项，而不是用推测补齐。

### 路径 C：处理日报、告警或待复核事项

适用场景：收到飞书日报、告警通知，或在工作台看到风险变化提示。

1. 打开 **采购工作台** 或 **风险监控**。
2. 优先查看“风险变化”“数据覆盖”和“下一步”字段。
3. 打开供应商详情，核对风险信号、数据时间、来源与业务影响。
4. 如需进一步分析，点击“Agent 复核”或进入 AI 采购助手，提出明确问题。
5. 根据建议选择继续观察、重新发起复核、转线下核验或开展替代寻源。
6. 风险监控页的复核任务按“创建—批准—执行”处理；AI 采购助手出现写操作审批卡时，再按审批卡选择批准或拒绝。
7. 执行完成后，查看任务结果、证据回写和页面状态。

## 4. AI 采购助手：提问方式与结果判读

### 4.1 推荐问题库

| 业务目的 | 推荐提问 | 回答中应重点查看 |
| --- | --- | --- |
| 单家风险复核 | `查看 XX 供应商的风险情况` | 当前结论、风险维度、证据和数据覆盖 |
| 风险依据追问 | `风险结论主要依据哪些数据？` | 数据来源、时间、事实与推断的区别 |
| 后续处理 | `这家供应商下一步建议怎么处理？` | 建议动作、优先级、待补充核验项 |
| 范围内风险查看 | `查看我负责的供应商近期风险变化` | 责任范围、变化对象、数据不足提示 |
| 专项风险分析 | `分析 XX 供应商的财务、司法和经营风险` | 各维度是否已覆盖，缺口是什么 |
| 智能寻源 | `找一下 XX 品类的供应商` | 候选分组、匹配品类、主营产品、来源和状态 |
| 候选边界 | `外部待核验候选和正式供应商有什么区别？` | 准入边界、仍需人工核验的事项 |

### 4.2 提问时如何写得更准确

- 尽量给出供应商全称、供应商代码或统一社会信用代码；
- 寻源时至少写明物料、品类或用途；有条件可补充规格、区域和交付要求；
- 连续追问时尽量留在同一会话，便于系统承接上一步的对象和问题；
- 一次只提出一个主要任务。需要比较多个供应商时，明确列出每一家名称和比较维度；
- 需要时间范围时直接写明，例如“近三个月”“本月”“最近一次快照”。

### 4.3 AI 回答的阅读顺序

建议按以下顺序阅读，而不是只看风险等级：

1. **对象是否正确：** 是否明确显示了要查询的供应商或物料；
2. **结论是什么：** 当前风险、变化或候选结果是什么；
3. **依据够不够：** 是否能看到来源、数据时间、风险信号或匹配说明；
4. **数据是否完整：** 是否存在未覆盖、缺失、失败或待确认；
5. **下一步做什么：** 是继续观察、重新发起复核、转线下核验，还是开展替代寻源；
6. **是否出现审批卡：** AI 采购助手的写操作以审批卡为准；不要把分析建议直接当成已执行的业务状态。

### 4.4 回答未完成或中断时

- 先等待页面出现“完成”“部分完成”或明确错误提示；
- 网络短断后，系统会尝试根据运行记录回放未显示的过程和结果；
- 不要在上一条结果未确认前反复发送完全相同的问题；
- 若显示“部分完成”，查看失败或未覆盖的数据域，决定重试、重新发起调查或转线下核验；
- 若出现主体待确认，请返回风险监控页，用供应商代码或统一社会信用代码重新发起调查并核对候选主体。

## 5. 风险监控：查看、复核与受控操作

### 5.1 查看监控对象

1. 点击 **风险监控**。
2. 列表会显示监控对象、身份状态、风险变化、数据覆盖、下一步和复核任务状态。
3. 优先处理“优先复核”“数据未覆盖”或风险变化明显的对象。
4. 点击供应商名称进入详情页。

详情页重点关注：

- 当前风险与风险变化；
- 数据覆盖范围和缺少的数据域；
- 风险结论与依据；
- 采购复核建议；
- 已有任务、审批、证据和更新时间。

### 5.2 新增监控对象

仅在确有持续监控需要、且已获得相应业务授权时执行。

1. 在风险监控页输入供应商名称、供应商代码或统一社会信用代码。
2. 系统展示可能匹配的主体，或提示使用更完整的名称、供应商代码或统一社会信用代码重新调查。
3. 核对企业名称、统一社会信用代码、法人、注册地址和来源信息。
4. 只有确认对象正确后，填写可选的核验依据/外部链接和确认说明（如页面展示），点击“确认此主体”。
5. 确认后，点击“确认主体并加入监控”，再检查是否已进入监控详情页并生成风险快照。
6. 如在 AI 采购助手中生成加入监控提案，则在对话中的审批卡上阅读操作内容后选择批准或拒绝；不要同时重复发起页面操作。

**不要做：**

- 仅凭名称相近确认企业；
- 对无责任范围或无业务需求的对象发起监控；
- 在页面未显示已加入监控或 AI 审批未执行完成前，将对象视为尚未加入监控。

### 5.3 移出监控或调整状态

移出监控属于业务状态变更，应由有权限人员根据业务规则处理。当前风险监控详情页提供“移出监控”及二次确认。

1. 在监控详情页查看最新风险、数据覆盖、任务和历史记录。
2. 确认移出原因和后续责任人。
3. 点击“移出监控”，在二次确认弹窗中确认执行。
4. 返回列表或刷新详情，确认该对象不再处于监控状态；如组织要求审批留痕，按既有线下流程办理。

## 6. 智能寻源：从候选线索到采购核验

### 6.1 填写采购需求

在 **寻源建议** 页面输入需求时，建议包含：

| 信息 | 示例 | 作用 |
| --- | --- | --- |
| 物料或品类 | 安全带、制动鼓、工业摄像头 | 确定检索范围 |
| 规格/能力 | IP67、防水、指定材料、特定工艺 | 提高候选匹配度 |
| 交付区域 | 华东、柳州、重庆 | 判断运输与服务可行性 |
| 质量或认证 | IATF 16949、特定检测能力 | 作为后续核验条件 |
| 交付约束 | 目标交期、预计批量 | 帮助采购员筛选和人工判断 |

填写完成后点击“开始寻源”，等待候选结果和待核验说明。

### 6.2 候选分组怎么理解

| 候选类型 | 含义 | 可做什么 | 不能直接做什么 |
| --- | --- | --- | --- |
| 历史合作供应商 | 与历史物料或采购关系有关联的对象 | 查看历史匹配信息，发起进一步复核 | 不能仅凭历史关系认定当前仍可供货 |
| 正式供应商 | 当前主数据中的供应商 | 查看已知资料和风险状态 | 不能忽略当前项目的质量、价格和产能要求 |
| 外部待核验候选 | 外部来源发现的潜在线索 | 查看来源、匹配说明、主营产品并发起调研 | 不能视为已准入、已认证或可直接定点 |

### 6.3 候选核验清单

每个候选至少应核对以下内容，并在组织既有流程中留痕：

- 供应商资料是否对应同一家企业；
- 主营产品和能力是否满足目标物料；
- 质量体系、资质和产能是否满足项目要求；
- 供货区域、交期、商务条件是否可接受；
- 当前风险信息和数据覆盖是否满足内部要求；
- 是否需要纳入持续监控或进入正式准入流程。

## 7. 供应商库与供应商画像

### 7.1 供应商库

供应商库展示的是正式供应商主数据的只读视图，用于检索、查看和进入风险分析。该页面不用于录入或修改供应商主数据。

使用方法：

1. 点击 **供应商库**；
2. 输入供应商名称、供应商代码或统一社会信用代码搜索；
3. 查看供应商基本资料、供货产品和来源；
4. 点击“查看画像”进入详情；
5. 如需风险结论，使用“问 AI”或进入风险监控页继续处理。

### 7.2 供应商画像

画像通常包含以下信息，实际内容取决于数据覆盖：

- 供应商基本资料和来源；
- 风险快照、风险历史或趋势；
- 财务、司法、经营、舆情等风险信息；
- 内部交易或采购快照；
- 关联关系与可用证据；
- 审计、复核和任务记录。

如果画像中某一区域为空，请查看是否提示“当前未覆盖”“暂无数据”或“需人工确认”，不要根据空白区域做风险判断。

## 8. 日报、通知、审批和复核任务

### 8.1 飞书日报与告警通知

系统可按责任范围汇总重点风险变化，并通过飞书日报或通知提示责任人。使用时请注意：

- 日报是提醒入口，不替代复核结论；
- 收到提醒后，应回到工作台查看具体供应商、数据时间和证据；
- 是否实际送达受飞书应用权限、接收人身份、责任关系和部署状态影响；
- 未收到日报时，先核对账号责任范围和飞书身份映射；通知投递日志由管理员在部署后台查询，普通用户页面没有查看入口。

### 8.2 AI 采购助手中的审批卡

AI 采购助手在生成受控写操作提案时，可能展示审批卡。风险监控页的“确认主体并加入监控”则是独立的页面确认流程，不以此审批卡为前置。

1. 阅读操作对象、拟执行动作和理由；
2. 核对操作是否在你的职责范围内；
3. 选择“批准”或“拒绝”；
4. 批准后等待页面返回执行结果；拒绝后确认未产生业务写入；
5. 返回对应页面确认最终状态。

审批卡不是普通聊天按钮。批准前请确保对象、范围和业务原因准确。

### 8.3 风险复核任务当前可操作范围

风险监控详情中的复核任务目前支持以下流程：

1. 查看任务类型、风险依据、待核验数据域和更新时间；
2. 创建复核任务后，在任务卡上批准或拒绝；
3. 对已批准任务点击“执行复核”；
4. 查看系统回写的执行结果、证据和任务状态。

当前页面**没有**人工上传补充证据、编辑复核结论、设置“待补充”状态或手动关闭任务的入口。若需要线下补证或继续跟进，请按组织既有流程处理；数据更新后可在系统内重新发起复核。

## 9. 结果状态速查表

| 页面状态 | 表示什么 | 用户应做什么 |
| --- | --- | --- |
| 已完成 / 分析完成 | 当前任务已返回可用结果 | 阅读依据和下一步建议 |
| 部分完成 | 部分工具或数据域未完成 | 查看缺口，决定重试、重新发起调查或转线下核验 |
| 当前未覆盖 / 数据不足 | 没有足够数据形成完整结论 | 不视为低风险，等待数据更新后重新发起复核或按组织流程线下核验 |
| 主体待确认 | 当前名称尚未与稳定供应商资料绑定 | 核对代码、统一社会信用代码等资料 |
| 等待审批 | 有写操作待人员确认 | 核对后批准或拒绝 |
| 权限不足 | 当前账号没有该对象的访问权限 | 联系管理员维护责任关系 |
| 执行失败 / 暂不可用 | 工具、网络或外部数据源异常 | 记录问题，稍后重试或转人工处理 |

## 10. 常见问题与处理建议

### 10.1 页面打不开或登录后无数据

- 确认前端、后端和数据库服务已启动；
- 确认账号已启用且有责任范围；
- 检查是否访问了正确的演示环境；
- 仍无法解决时，记录页面、时间、账号角色和错误提示，联系管理员。

### 10.2 为什么没有财务、趋势或舆情数据

常见原因包括：供应商非上市、数据源未配置、报告期不足、接口权限受限或当前数据未同步。应将页面状态记录为“未覆盖/待补充”，不要自行推断为风险较低。

### 10.3 系统要求确认供应商资料

请返回风险监控页，使用供应商全称、供应商代码或统一社会信用代码重新发起调查，并核对候选企业的登记信息。系统不会仅因名称相似自动绑定企业，这是为了避免错误监控和数据混淆。

### 10.4 AI 回答与预期不一致

- 核对问题中是否写清供应商、物料、时间范围和分析维度；
- 查看回答中的对象识别和数据覆盖说明；
- 新任务请使用“+ 新对话”，避免上一轮上下文影响；
- 记录原始问题、时间和页面状态，反馈给项目管理员。

### 10.5 飞书日报没有收到

确认本人飞书身份已映射、责任关系已配置、通知权限和部署任务正常；需要核对投递日志时联系管理员在部署后台查询。没有日报时仍可在工作台主动查看风险监控。

## 11. 管理员与运维边界

本节为部署后台和运维侧操作说明，不是普通用户可在“设置”页面完成的操作。当前前端“设置”页仅支持查看账户信息和修改密码。

管理员建议按以下频率检查：

| 频率 | 检查内容 |
| --- | --- |
| 每日 | 服务健康、定时任务、日报/通知投递、异常日志 |
| 每周 | 供应商主数据与责任关系同步、外部数据源可用性、待审批与待复核任务 |
| 每次发布前 | 登录与权限、核心问答、寻源分层、审批链路、SSE 回放、构建与回滚预案 |
| 出现异常时 | 记录问题、保护运行证据、评估影响范围、按发布与回滚手册处理 |

管理员不得在文档、聊天记录或前端页面暴露生产密钥、数据库密码和第三方 API 凭据。
