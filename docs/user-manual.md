# SuppliSense 使用说明书

**版本：** 0.3.0
**适用对象：** 采购员、科室经理、系统管理员
**更新日期：** 2026-09-11

## 1. 系统简介

SuppliSense 是供应商风险复核与智能寻源工作台。它把企业公开信息、上市公司财务信息、内部采购月度快照、飞书供应商主数据和历史供应商关系汇总起来，帮助采购人员发现风险变化、查看证据、安排复核并寻找候选供应商。

系统输出的是“可追溯的复核线索和建议”，不能替代供应商准入、现场审计、合同审批或质量判定。

## 2. 登录与角色

打开系统地址进入登录页，使用管理员发放的用户名和密码登录。登录成功后，系统会按照当前账号的角色和供应商责任范围过滤数据。

| 角色 | 可查看范围 | 典型操作 |
| --- | --- | --- |
| 采购员 | 本人负责的正式供应商、监控对象、风险快照和告警 | 供应商复核、寻源、查看通知、提交复核动作 |
| 科室经理 | 所属科室采购员负责的供应商 | 查看团队风险、复核任务和告警汇总 |
| 管理员 | 全量演示数据及运维功能 | 用户管理、数据同步、告警管理和系统维护 |

如看到“权限不足”，通常表示企业不在当前账号的责任范围内。不要通过修改查询条件绕过范围控制，应联系管理员维护责任分配。

## 3. 页面说明

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| AI 工作台 | `/chat` | 用自然语言发起供应商风险复核、范围查询、趋势分析和寻源问题 |
| 总览 | `/` | 查看责任范围内的风险摘要、告警趋势和监控概况 |
| 智能寻源 | `/sourcing` | 按物料号、物料名称或品类查找历史供应商和外部候选 |
| 风险监控 | `/assess` | 调查企业主体、确认绑定、查看风险依据和处理复核任务 |
| 供应商库 | `/suppliers` | 浏览正式供应商主数据并打开供应商画像 |
| 设置 | `/settings` | 查看当前账号及可用系统设置 |

## 4. 常用操作

### 4.1 使用 AI 工作台进行风险复核

1. 进入“AI 工作台”。
2. 输入明确的问题，例如：
   - `请复核 XX 供应商最近的风险变化，并列出证据和需要核实的资料。`
   - `查看我负责的供应商本月风险变化。`
   - `分析 XX 供应商的财务、司法和经营风险。`
   - `按物料号 12345 查找历史供应商和外部候选。`
3. 等待系统完成理解需求、执行数据核验和证据整理。
4. 查看“本轮分析结果”“证据与数据来源”“数据边界”和“建议动作”。
5. 如系统要求澄清企业主体、物料或时间范围，请补充信息后重新提交。

AI 工作台会展示执行详情、工具调用和证据校验状态。网络中断时，页面会按运行 ID 尝试回放尚未显示的结果；不要在结果未确认前重复提交同一问题。

### 4.2 调查并加入风险监控

1. 在“风险监控”页点击新增，或在供应商画像中选择“加入风险监控”。
2. 输入企业名称、统一社会信用代码、天眼查链接或供应商代码中的已知信息。
3. 从主体候选中选择正确企业。名称相近时，必须核对统一社会信用代码、法人、注册地址等信息。
4. 查看数据覆盖范围和风险摘要。
5. 确认后创建监控对象。

如果没有足够信息确认主体，系统会停在“主体待确认”，不会自动绑定相似企业。监控对象创建后，可在详情页查看风险依据、历史快照、趋势、复核任务和告警。

### 4.3 查看供应商画像

在“供应商库”中选择供应商，进入画像页。画像包含：

- 概览：风险评分、舆情、制裁筛查和近期告警；
- 风险：司法、经营异常、被执行、失信、行政处罚、ESG 等信息；
- 财务：营收、净利润、增长率、偿债与流动性指标；非上市企业可能没有财务数据；
- 关联：关联企业、分支机构、供应链依赖及风险关系图；
- 日志：供应商信息或风险变化记录。

### 4.4 使用智能寻源

1. 进入“智能寻源”。
2. 输入物料号、物料名称或品类，必要时补充规格、地区和能力要求。
3. 先查看“历史合作供应商”和“正式供应商”。
4. 再查看“外部待验证候选”，重点核对候选来源、主体身份、资质、联系方式和风险信息。
5. 将候选作为采购调研线索，按组织流程完成资质、质量、价格和产能核验。

外部候选不等于已准入供应商，系统不会因为候选匹配就自动写入正式供应商主数据。

### 4.5 处理告警与复核任务

1. 在总览、风险监控或通知中心查看新的风险信号。
2. 打开告警详情，确认触发维度、数据时间和证据来源。
3. 创建或打开采购复核任务，补充合同、交付、质量、财务或主体资料。
4. 需要执行加入/移出监控等写操作时，按照页面提示提交人工审批。
5. 审批通过后再执行；审批拒绝则不会写入对应监控清单。

## 5. 风险结果如何理解

系统会区分以下状态：

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 分析完成 | 任务已完成，存在可验证结果 | 阅读证据并决定是否需要采购复核 |
| 发现信号，需人工复核 | 发现异常或风险变化，但不能代替人工判断 | 核对原始资料和业务影响 |
| 当前未覆盖 | 当前数据源不足，不能据此判断正常 | 补充资料或等待数据源更新 |
| 主体待确认 | 尚未把名称绑定到确定企业主体 | 核对统一社会信用代码等身份信息 |
| 权限不足 | 当前账号无权访问该对象 | 联系管理员检查责任分配 |
| 部分完成/暂未完成 | 部分工具失败、超时或没有返回结果 | 查看数据边界，稍后重试或人工补充 |

风险评分为辅助指标。采购判断应同时考虑证据、数据覆盖率、时间范围、供应商实际业务和人工核实结果。

## 6. 数据来源与使用边界

| 来源 | 主要用途 | 使用注意 |
| --- | --- | --- |
| 天眼查 | 工商、司法、经营异常等主体风险 | 不等同于现场审计或质量结论 |
| 上市公司财报 | 盈利、现金流、偿债和财务趋势 | 非上市企业可能无公开财报 |
| 内部采购月度快照 | 交易连续性、结算金额或收货记录变化 | 收货记录数不等于零件数量、采购金额或交付能力 |
| 飞书供应商主数据 | 正式供应商、责任归属、科室和采购员 | 当前以只读同步为主，不在本系统维护源表 |
| 外部候选库/网络发现 | 寻源线索 | 必须完成主体、资质和采购流程核验 |

当页面显示“数据待补充”时，不应把它理解为“未发现风险”。

## 7. 管理员操作

管理员负责：

1. 创建、停用和维护系统账号；
2. 配置供应商责任分配和角色范围；
3. 按需执行飞书供应商主数据和责任分配的只读同步；
4. 检查数据库、Redis、外部数据源和模型服务状态；
5. 查看通知投递、任务执行、审计和错误记录；
6. 执行备份、恢复和发布回滚流程。

生产环境不应把真实密钥写入代码、README 或 Git；环境变量文件也不应提交到仓库。

## 8. 常见问题

### 页面打不开

先确认前端服务、后端服务和数据库已启动，再访问后端就绪检查地址：`/health/ready`。Docker 部署可使用 `./start.sh` 启动、`./stop.sh` 停止。

### 登录后页面为空

检查账号是否启用、是否已配置供应商责任分配，以及对应数据源是否完成同步。采购员默认只能看到本人负责的数据。

### 没有财务或趋势数据

可能是企业非上市、数据源未配置、报告期不足或当前数据覆盖不满足绘图条件。请按页面提示补充资料，不要将空结果理解为低风险。

### 监控对象无法确认

补充统一社会信用代码、天眼查链接或供应商代码，并核对主体候选。系统不会仅凭名称相似度自动绑定。

### AI 返回需要人工复核

这通常表示存在风险信号、证据不足、数据冲突或需要执行的写操作。查看证据和数据边界；写操作必须通过人工审批。
