# 比赛演示检查清单

## 启动检查

1. 启动后端和前端。
2. 打开 `http://127.0.0.1:5173/login`。
3. 确认后端 `http://127.0.0.1:8000/health/ready` 返回 `status=ready`，且 MongoDB、Redis、PostgreSQL、Harness checkpointer 均为 `ok`。

## 主流程

1. 使用管理员账号登录，进入 AI 工作台。
2. 输入“复核青岛三祥科技股份有限公司”。
3. 展示上市公司盈利变化、交易连续性、证据表和趋势图。
4. 输入“复核上海汽车制动系统有限公司”。
5. 展示结算环比变化、财务信息覆盖边界和采购复核事项。
6. 展开执行详情，展示任务、审批、执行结果和证据回写状态。

## 权限与边界

1. 使用采购员账号登录，确认只能看到责任范围内的供应商。
2. 输入其他采购员负责的正式供应商名称，确认 Agent 返回无权访问且不泄露明细。
3. 输入不在供应商库的企业名称，确认系统说明无法按正式供应商复核；如用户要求评估外部企业，再展示主体检索和待验证数据边界。

## 寻源流程

1. 输入“帮我为后轮制动鼓寻找历史供应商和外部候选”。
2. 展示历史合作供应商、盖世外部候选和“外部待验证候选”标识。
3. 对外部候选执行主体核验，确认未核验主体不会直接进入正式供应商目录。

## 讲解口径

- 收货记录数表示源明细行数，不等于零件数量或交付能力。
- 结算波动是复核信号，不单独等同于供应中断或经营风险。
- 没有财报的非上市供应商只展示数据覆盖边界，不生成虚假财务结论。
- Agent 的结论始终展示证据来源、可信度和采购人员下一步动作。
