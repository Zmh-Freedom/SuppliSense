二、ReAct Graph（默认图，单 Agent + 全量工具循环）

graph TB
    START([用户消息]) --> SYS[SystemMessage + 偏好注入]
    SYS --> AGENT[agent 节点
LLM bind_tools]
    AGENT --> DECIDE{有 tool_calls?}
    DECIDE -->|yes| TOOLS[ToolNode
执行工具调用]
    TOOLS --> AGENT
    DECIDE -->|no| DONE([SSE done])
    AGENT --> STREAM[SSE answer_chunk
token 级流式输出]

六、SSE 事件流 & 数据持久化

sequenceDiagram
    participant U as 用户
    participant F as ChatView.tsx
    participant A as /api/v1/chat/stream
    participant G as LangGraph
    participant T as ToolNode
    participant D as MongoDB

    U->>F: 输入问题
    F->>A: POST {message, session_id, mode}
    A->>A: IntentRouter 分类
    A->>A: 偏好注入
    A->>G: 启动执行图

    loop ReAct 循环
        G->>G: LLM 推理
        G-->>F: SSE: thinking
        G->>T: tool_call
        G-->>F: SSE: tool_call
        T-->>F: SSE: tool_result
        T->>G: 工具结果
    end

    G-->>F: SSE: answer_chunk (流式)
    G->>D: _save_turn
    G-->>F: SSE: done
    F->>U: 渲染答案
